## 这是什么

本工具在你的电脑上运行一个本地网关与管理面板，把 Devin 的模型流量无缝转接到任意第三方线路。Devin 端零改造、账号零影响：启动即接入，停止或还原即恢复原始状态，不残留任何改动。

核心价值在于三点：

- **线路自由**——模型请求走你的中转站与密钥，成本与稳定性自己掌控
- **模型自由**——路由映射 + 自定义模型，Devin 模型列表按你的需要重塑
- **状态干净**——接入、热更新、还原全程自动化，随时一键回到官方状态
